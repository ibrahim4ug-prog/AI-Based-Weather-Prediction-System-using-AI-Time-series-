# Sample data

`weather.csv` contains **synthetic** daily data (1,096 rows, 2022-01-01 to 2024-12-31) generated
by `generate_sample_data.py` with a fixed random seed. It is **not** an actual weather observation
and must not be used to draw conclusions about any real location.

Columns: `date`, `temperature` (°C), `humidity` (%), `rainfall` (mm), `wind_speed` (km/h), `pressure` (hPa).
